# Get started with Promptly

1. Download `Promptly.zip` from the repository's **Releases** page and double-click it to unzip.
2. Drag `Promptly.app` to your **Applications** folder, then open it.
   - If macOS blocks the first launch, Control-click the app, choose **Open**, then choose **Open** again.
3. Click the viewfinder in the menu bar and choose **Settings…**.
4. Choose MiniMax, OpenAI, or Anthropic, paste **your own** API key for that provider, then select **Save securely**.
5. When macOS asks, allow **Screen Recording** for Promptly. You can also enable it later in **System Settings → Privacy & Security → Screen & System Audio Recording**.
6. Keep the material you want to read visible, then press **Control–Shift–|**. Change the shortcut in Settings whenever you like.

Promptly does not continuously record your display: it reads the currently visible screen only after you use the shortcut. It sends the text it recognizes—not the screenshot itself—to the provider you select. Use it only where AI assistance is allowed.
